# 野埼タイマーの使い方

対象バージョン: **KanColle-YPS v2.3.1 +NozakiTimer v1.0.1**

導入と更新は [README](../README.md)、変更内容は [バージョン変更情報](../CHANGELOG.md) を参照してください。

## 計測の開始

野埼または野埼改を旗艦・2番艦に置き、給糧対象の随伴艦を編成します。通常の編成変更が成功すると、全艦隊共通の経過時間を計測します。F12を閉じていた間の編成操作は観測できません。

## 表示

- 要約は「野崎タイマー: 経過 15:30, 推定cond 52（最大54）」のように太字で表示します。
- 見出しの三角をクリックすると、艦隊ごとの「推定cond」「艦名」「取得値・状態」を展開できます。
- 要約のcondは全対象艦の最低推定値です。不明な値を含む場合は不明とします。
- 最低推定condが54に達すると、要約行が鮮やかな赤色に切り替わります。色の切替に再読み込みは不要です。
- 野埼の対象艦隊がない場合は「経過 -:--, 対象艦隊なし」、随伴艦がいない場合は「給糧対象艦なし」と表示します。
- 初回の母港受信前および出撃・戦闘中は非表示です。母港受信で再表示します。開閉状態はタイマーの表示更新で維持されます。

## リセットの扱い

対象艦隊の通常の編成変更が成功すると、計測を開始し直します。艦隊間移動は両方の艦隊を確認します。編成キャッシュが先に更新されている場合も、既存YPSが解析した変更艦隊番号を使って判定します。

プリセット、一括解除、解体・改修による前詰め、出撃・演習、改造ではリセットしません。対象から外れた場合は母港側で「対象艦隊なし」と表示し、内部の観測時刻は保持します。プリセットで戻した場合と通常編成で戻した場合を区別します。南海は給糧艦として判定しません。

## 推定condの範囲

給糧タイマーの開始時刻を直接取得できないため、編成変更と母港受信時のcond差分から推定します。実際のcondや燃料を書き換える処理はありません。

計測開始から15分に安全余裕30秒を加え、最終受信値で適用条件を満たす艦に、給糧一回分の見込みを加算します。上限は54です。実値を受信するまで繰り返し加算せず、自然疲労回復も加算しません。「母港反映待ち」は、母港へ戻った場合の見込みを示します。

燃料不足・燃料不明・条件未達の場合は安全側の値を維持します。入渠、損傷、補給、野埼のcond等も最終受信値で判断します。母港で新しい実値を受信したら計算し直し、推定分を二重加算しません。

自然回復の上限49を越える給糧相当の上昇を母港で観測した場合は、次の周期の起点を推定します。これは給糧確定通知ではありません。判別できない場合は起点を勝手に進めません。

F12の開き直しや拡張機能の再読み込み後は、未観測の操作を補完せず「開始時刻不明」とします。プリセットだけでは未知の開始時刻を確定できません。

## 出典

[艦これWiki「野埼・母港給糧艦システム」](https://wikiwiki.jp/kancolle/%E9%87%8E%E5%9F%BC#FoodSupplyShip)を参照しています。安全余裕30秒、観測できない場合の扱い、最低condの要約表示は本ツール独自の設計です。

## 検証

拡張機能のソースフォルダで実行します。

```text
node --test test/nozaki-test.cjs
```

開始・保持・リセット、15分境界、cond/損傷境界、7番艦、入渠、燃料・弾薬、成功・失敗応答、プリセット、艦隊間交換、表示更新を検証します。実ゲームでの利用確認報告もありますが、全条件・全環境の網羅検証を意味しません。
