# 通常海域・遠征の条件確認

確認日: 2026-10-04。サイトは確認時に参照し、実行時には通信しません。

## 通常海域

ぜかましの37海域を確認。ゲージ・ギミックを分けた45項目、144パターン（うち高速＋の4件は参考表示のみ）を登録しています。記事の具体例とルート条件を艦種別に整理したもので、画像編成・装備の完全再現ではありません。

- 自動比較は異なる艦種構成を最大3案。足りない場合に同艦種の艦娘違いで埋めません。
- 「編成パターン」で4案目以降や特定ルートを選択できます。候補数1の海域は重量編成を捏造しません。
- 5-6、7-2、7-3、7-5は攻略段階を分離。5-6の出典は暫定ルート情報を含みます。
- 羽黒・足柄・神風・翔鶴・瑞鶴・秋津洲の指定枠と軽巡／駆逐旗艦を照合します。通常高速は艦マスターの速力で保守的に判定し、装備で高速化した低速艦は自動採用しません。
- 高速＋を通常高速と同一視しません。缶・タービンによる装備後速力を保証できないため、該当案は参考表示とします。
- 装備配分は従来の役割別提案です。ドラム缶、対地装備、特殊攻撃艦、制空・索敵・先制対潜の充足は別途確認。特殊攻撃を使う記事の一般艦種への置換は同等の戦果を保証しません。

### 判定の限界

- 火力・対空・対潜・索敵の最低値は表示しますが、改修・艦載機補正込みの遠征専用計算は未実装です。数値を満たしたとは判定しません。
- 代替編成がある遠征では基本例との一致を判定し、例外を照合できない場合は「未判定」。B6・D3・32の大成功条件など、出典の検証中表記を維持します。
- 24・40のドラム缶は成功には不要、大成功の確定目安に必要。東京急行37は成功4個／3隻、大成功目安5個／3隻＋キラ4隻。38は成功8個／4隻、大成功目安10個／4隻＋キラ4隻。
- 大成功欄は成功条件を満たすことが前提。確定目安未達は大成功不可能の意味ではありません。
- 通常戦闘用の装備配分を遠征装備案として表示する処理をやめ、照合対象の現在装備を表示します。ゲームの艦隊や装備は変更しません。

## 変更箇所と確認

- `map-profiles.js`: 海域別・段階別データ。`generator.js`: 指定艦／旗艦条件と異なる艦種構成の選出。`generator-ui.js`: パターン選択と各案の注意事項。
- `expedition-data.js`: 63件の条件。`expedition-rules.js`: 個別条件の照合。`expedition-ui.js`: 成功／大成功の集約表示。
- テスト: 同艦種の水増し禁止、ゲージ分離、史実艦・旗艦・高速条件、ドラム缶数と搭載隻数の独立判定、欠損値、改修前後の条件差、画面切替。実ゲームでの到達・勝利・遠征成功は未検証です。
