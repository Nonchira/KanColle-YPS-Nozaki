# 配布とフォーク準備

## 配布物

リポジトリのルートで次を実行します（Python 3）。出力先は既存ファイルを指定しないでください。

```text
python tools/package-release.py --output ../KanColle-YPS-Nozaki-v1.0.2.zip
```

配布対象は明示されたファイル一覧です。.git、ブラウザの保存領域、個人用設定、作業ログ、バックアップ、内部knowledge-domain.json、過去の更新ツール実行結果は含めません。ZIP内のUpdate/release-files.jsonに、収録対象とSHA-256を記載します。

通常利用に必要なソースとアイコン、利用案内、仕様、出典、合成テスト、Update資料を同梱します。ZIPを展開したフォルダは、そのまま拡張機能として読み込めます。

## GitHubへ準備する場合

1. オリジナルのForkを作成する場合は、その履歴と原作者表記を維持します。
2. 公開する作業ツリーに、この配布物の内容を反映します。既存のローカル.gitや作業履歴はそのまま公開しません。
3. READMEに基準版・追加機能・制限を示し、派生版の変更履歴と出典を保持します。
4. 権限・参照・テスト・個人情報の検査後に、差分をレビューしてコミットします。

実際のFork作成・アップロード・Issue/PR投稿は、この配布作成処理には含みません。manifestのhomepage_urlは本派生版の公開リポジトリを指します。

## 配布前確認

```text
python tools/check-release.py
node --test test/*.cjs
node --test compass/tests/*.test.js
```

機械検査はすべての個人情報や再利用条件を保証するものではありません。ソース・テスト・ドキュメントを目視で確認し、実プレイの受信内容・画像・認証情報・ブラウザDBを追加しないでください。
