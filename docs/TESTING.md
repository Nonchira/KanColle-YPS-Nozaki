# 検証手順

## 自動検証

Node.js 22以降を目安に、配布ルートで実行します。

```text
node --test test/*.cjs
node --test compass/tests/*.test.js
python tools/check-release.py
```

テストは架空データを使います。実通信ログやブラウザDBを必要としません。検査対象はタイマー・戦果・元表示・欠落艦隊・正規化・任務周期・ジェネレーター・履歴・ドロップ・受信本文等です。

## ブラウザ検証

Node.jsだけではIndexedDBとDOMの実動作は検証できません。配布ルートから `python -m http.server 8767 --bind 127.0.0.1` を起動し、通常利用とは別のテスト用ブラウザプロファイルで `http://127.0.0.1:8767/compass/tests/browser.html` を開きます。ローカルサーバーはファイル表示用であり、ゲーム通信を行いません。テスト終了後は停止してください。

このテストはそのローカルサイトのIndexedDBに合成記録を書きます。拡張機能のURLで実行して実プレイ記録を混ぜないでください。

## 実ゲーム確認

- GAME START前にF12を開き、YPS母港表示を確認。
- コンパスを開き、受信履歴・通常海域／遠征の別連番・ドロップ・任務を確認。
- 通常編成変更時のタイマー開始、出撃時の非表示、帰港時の再表示を確認。
- 記録がない状態と読み込み中を区別できること、初回起動でYPSを長時間待たせないことを確認。
- 最新上流へ移植した場合は権限・受信形式・データ保持・再読込も確認。

## v1.0.0の確認範囲

公開前の検証結果は配布に対応する自動テストと参照・ハッシュ検査で確認します。安定性・起動速度は通常プレイで確認された構成を基準としますが、全ブラウザ・全任務・全海域・将来のゲーム仕様を保証するものではありません。

公開基準の検証結果: YPS側42件、コンパス側67件、合計109件のNodeテストが通過。隔離ブラウザでIndexedDB等16項目、ダッシュボード・ツールバー・診断非表示を確認しました。基準ファイルへのpatch適用と公開版との一致も確認しています。

任務警告の回帰テスト: `node --test test/quest-warning.test.cjs`。先行一覧と報酬受取の順序、後続一覧なしの保存、全All再確認、絞り込みページ、実際の達成表示を確認します。

任務定義索引は従来の全件照合との一致をテストします。合成履歴3,000件の比較では約13秒から約48msに短縮し、集計出力が一致しました。実プレイの画面待ち時間そのものの測定ではありません。
